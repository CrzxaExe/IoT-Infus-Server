# Infus Monitoring Server

## Overview

Infus Monitoring Server is a server-side project for an infusion monitoring system. This repository contains the source code currently available for the project. Development is ongoing, so features and documentation may change as the project evolves.

> [#IMPORTANT]
> This Repo

## Current Features

- Real-time infusion status monitoring through the backend server.
- Patient data management and infusion schedule configuration.
- Storage of monitoring data for analysis and tracking purposes.
- Server API that can be used by client applications or monitoring devices.
- Project structure ready to be extended with additional features such as notifications, dashboards, and further integrations.

## Getting Started

### Download the Project

Install Git, then clone the repository. Replace `<repository-url>` with the repository's Git URL:

```bash
git clone https://github.com/CrzxaExe/IoT-Infus-Server.git
cd Iot-Infus-Server
```

Alternatively, download the repository as a ZIP file, extract it, and open a terminal in the extracted project folder.

### Install Dependencies and Run the Server

Install the runtime required by the project, then install its dependencies using the instructions for its technology. For example, if the project contains a `package.json` file and uses npm:

```bash
npm install
npm start
```

Run the start command defined by the project if it differs from `npm start`. After startup, check the terminal output for the server address and port, then open that address or use it to configure a client. If the project uses a different technology, use its dependency and run commands instead.
